ScanScript
====

ScanScript - это небольшой скрипт на shell, использующий инструмент Nmap, сделанный с целью облегчения этапа активной разведки.
Сам по себе скрипт лишь собирает информацию о открытых портах и том какие сервисы установлены на данных портах.

Установка
----------
Все что нужно это просто скачать скрипт и набрать следующие команды

    chmod +x script.sh
    sudo ./script.sh
P.S sudo требуется Nmap'у для определенных флагов

Настройки
----------
В скрипте предусмотрено только 2 настройки ("Быстрое сканирование" и "Полное сканирование")
С тем за что отвечают данные настройки можно разобраться в самом коде скрипте, но если кратко быстрое - проверка первых 1000 портов, полное сканирование - проверка всех 65535
